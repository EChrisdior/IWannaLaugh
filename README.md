# IWannaLaugh

A small React site for the Viral Roast generator.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open the URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Deploy

This app can be deployed as a static site on platforms like Vercel, Netlify, or GitHub Pages.

- Vercel: Connect the repository and use `npm run build`.
- Netlify: Connect the repository and use `npm run build`.
- GitHub Pages: A workflow will publish the `dist/` directory to the `gh-pages` branch.
